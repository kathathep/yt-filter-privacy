# Privacy Policy — YT Filter — Just Keywords

Static page for the Privacy Policy of the Chrome extension **YT Filter — Just Keywords**, published with GitHub Pages.

- `index.html` — the Privacy Policy page (plain HTML + inline CSS, no JavaScript, no external resources, no cookies, no analytics)
- `README.md` — this file

## Publish with GitHub Pages

1. Create a new **public** repository on GitHub (any name, for example `yt-filter-privacy`).
2. Upload `index.html` (and this `README.md`) to the **root** of the `main` branch.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment → Source**, choose **Deploy from a branch**.
5. Set **Branch** to **main** and the folder to **/ (root)**, then click **Save**.
6. Wait for the deployment to finish (Settings → Pages shows the site address when it is live).

The published address has this form:

```
https://<your-github-username>.github.io/<repository-name>/
```

Open the address in a browser to confirm the page loads, then paste it into the Chrome Web Store Developer Dashboard as the **Privacy policy URL**.

## Updating the policy

If the extension's data practices change:

1. Edit `index.html` so it matches the new behavior.
2. Update the date in the `<time>` element near the top of the page.
3. Commit to `main`; GitHub Pages redeploys automatically.
